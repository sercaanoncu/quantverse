# QuantVerse Context

QuantVerse is a research-grade multi-asset portfolio analytics and risk
validation project. It includes the legacy ETF/multi-asset pipeline plus global
stock-selection and global master-portfolio research layers.

Start repo work from `AGENTS.md`, `PROJECT_CONTEXT.md`, `PIPELINE_CONTEXT.md`
and `.codex/VALIDATION.md`.

Current capabilities include portfolio construction, risk metrics, Equal Weight
comparison, random portfolio benchmarking, Black-Litterman, Monte Carlo,
stress tests, projection horizons and strict `not promoted` outcomes.

The global quant pipeline requires sourced global equity universe inputs before
any real global master portfolio can be promoted. Current top-100 constituent
lists are forward-looking research inputs only.

Do not fabricate top-100 tickers, market caps, ranks or source URLs. Current
constituents are not point-in-time historical evidence. Historical claims require
point-in-time constituents, market caps, FX, corporate actions, delistings and
calendar handling.
