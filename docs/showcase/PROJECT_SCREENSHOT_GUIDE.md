# QuantVerse Project Screenshot Guide

## Recommended Screenshots

1. Terminal output from `python scripts/run_quantverse_v2_demo.py --config configs/global_quant_research.yaml`.
2. `data/processed/quantverse_v2_demo_summary.json`.
3. `data/processed/global_stock_scores.csv` filtered to selected rows.
4. `data/processed/global_portfolio_league.csv`.
5. `data/processed/global_portfolio_league_weights.csv`.
6. `data/processed/global_walk_forward_model_comparison.csv`.
7. `output/pdf/quantverse_v2_research_report.pdf`.
8. `output/excel/quantverse_v2_research_output.xlsx`.

## Caption Rules

- Say public-data research, not institutional point-in-time proof.
- Say selected candidate, not buy recommendation.
- Show final weights and risk metrics together.
- Show blockers and limitations in the same package as performance outputs.
