# QuantVerse v2 Formula and Theory Registry

This registry is the active formula contract. Decimal returns use `0.01 = 1%`.
Daily observations use 252 trading days unless a file explicitly states
otherwise. Book abbreviations: **P** Palomar, **S** Severini, **A** Ahlawat,
**H** Hull, **ISLR** *An Introduction to Statistical Learning*, **MLAT**
*Machine Learning for Algorithmic Trading*, **MLF** Dixon/Halperin/Bilokon,
and **QE** *Quantitative Economics with Python*.

| Name | Notation and exact implementation | Inputs / frequency / units | Output / sign / annualization | Assumptions and missing-data policy | Theory and sources | Independent test and edge cases | Invalidation conditions |
|---|---|---|---|---|---|---|---|
| Simple return | \(R_t=P_t/P_{t-1}-1\); `prices.pct_change(fill_method=None)` | Adjusted prices; daily; price units cancel | Daily decimal; may be negative, never below -1 | No implicit forward fill; missing price yields missing return | S, A, P, MLAT | Recomputed from prices | Unadjusted corporate action, stale/zero-filled price, return below -100% |
