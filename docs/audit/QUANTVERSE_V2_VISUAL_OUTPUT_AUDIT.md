# QuantVerse v2 Visual Output Audit

## Scope And Current Decision

This audit governs chart-ready evidence generated from the corrected v2
public-data equity pipeline. It does not select a model independently.

Current clean-run decision:

- public-data research model: **Equal Weight**;
- model decision: `not promoted`;
- institutional/global-master promotion: `not_promoted`;
- reason: no active challenger clears paired uncertainty, robustness,
  random-benchmark, downside-risk, cost, and metric-review gates.

## Methodology Basis

contracts follow the metric and unit definitions in

## Output Contract

Every chart-ready CSV must state:

- formula or method;
- source basis;
- why the construction is valid;
- limitation;
- invalidation condition;
- test or validator;
- evidence status.

No chart can convert a point estimate into a promotion decision.

## Permanent Failure Conditions

The visual layer fails if:

- it fabricates Equal Weight when no final decision exists;
- it uses weights from a different model league or run;
- equity does not start at 1.0;
- drawdown is positive;
- risk/return axes are reversed;
- forecast error lacks a same-horizon random-walk comparator;
- random portfolios are degenerate or constraint-incomparable;
- exposure does not reconcile to one;
- an extreme point estimate is styled as success without a warning;
- PDF/HTML/Excel hides model status, scope, or blockers;
- a raw table dump replaces interpretation.
